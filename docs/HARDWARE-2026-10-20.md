# Hardware validation record — 20 October 2026

## Device and connection

- W610 address: `192.168.8.187`
- Host name reported by network diagnostics: `tnc415`
- PC address on the private Wi-Fi network: `192.168.8.186`
- W610 HTTP interface: reachable
- W610 WebSocket port: `8000`
- Stock WebSocket page: `http://192.168.8.187/websocket.html`

## Verified stock implementation

The page constructs:

```javascript
socket = new WebSocket('ws://' + window.location.host + ':8000');
socket.binaryType = "arraybuffer";
```

The binary send function parses hex pairs into a `Uint8Array` and calls:

```javascript
socket.send(sendArray);
```

The receive function handles `ArrayBuffer` by wrapping it in a `Uint8Array`.

Both WebSocket probes were closed immediately without transmitting serial data, to avoid sending arbitrary bytes to a connected TNC.

## UART configuration after restart

The W610 configuration page reported:

- Transparent mode
- 38400 baud
- 7 data bits
- Even parity
- 1 stop bit
- Flow control disabled

This confirms the stored W610 UART configuration is `38400 7E1`.

## Not yet verified

- W610-to-PC or W610-to-TNC loopback.
- Byte-exact delivery of all 7-bit control codes through the physical serial link.
- W610 packet latency and free-frame boundaries.
- Any FE1 directory or file operation.

The current test boundary is intentional: endpoint and configuration verification only, with no arbitrary payload sent to the TNC.
